# OpenRay 演示速查（v2.3）

## 启动

```bat
run.bat
:: 或
python -m screenlight
```

## 键盘

| 键 | 作用 |
|---|---|
| `Ctrl+M` | 循环 跟随 / 画布 / DJ |
| `Ctrl+1/2/3` | 音源：内置 / 麦克风 / 系统内录 |
| `Ctrl+S` | 光感复位（灵敏度 40% / 基础亮度 8%） |
| `Ctrl+←/→` | 上一首 / 下一首 |
| `Space` | 暂停 / 继续 |
| `F2` | 触发唤醒：桌宠竖耳/亮眼/气泡「我在」约 2.6s |
| 点击桌宠 | 打开控制面板（默认一级菜单） |
| `Ctrl+Alt+B` | 爆闪开关（亮度≥90% 纯白，否则纯黑） |
| `Ctrl+Alt+L` | 循环 光影：自动/四列/海浪/窗光/追光/关 |
| `Ctrl+Alt+X` | 小茂模式：仅宠物周围亮度蒙版 |
| 桌宠拖动 | 移动光灵猫 |
| 桌宠双击 | 下一首 |
| 桌宠长按 | 暂停 / 继续 |
| 桌宠右键 | 打开面板 / 换一副尾巴 / 小茂模式 / 退出 |
| Agent「换尾巴」 | 立即重掷 1–9 根尾巴 |
| `Esc` | 退出 |

## 说明

- 唤醒是后台常驻的可选 KWS；默认关闭以免 Windows 通信音频压低。用 `--kws auto` 开启，默认词「小茂」。
- 栏杆已替换为光弦滑杆；`--safety` 仅作旧脚本兼容（strict→10% / comfort→40% / off→60%）。
- 演示视频、PPT、海报和可运行包见 `submission/`。
